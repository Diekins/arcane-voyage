# assets/audio/ambient — drop-in da fundação de áudio ambiente

Solte um `.ogg` aqui com o **nome exato** e a camada **acende sem código** (depois rode `--import` 1x).
Sem o arquivo, a camada fica **dormente** (silenciosa, sem erro). Ver `docs/AMBIENT_AUDIO_FOUNDATION_BUILD.md`.

| Camada | Arquivo | Regiões |
|---|---|---|
| Global | `global_bed.ogg` | todas (leito quase-mudo, "ar do mundo") |
| Regional | `region_cave_stone.ogg` | Caverna, Poço do Ferro-Velho |
| | `region_coast.ogg` | Costa, Banco de Areia, Ilha do Sal |
| | `region_village.ogg` | Vila dos Novatos |
| | `region_desert_city.ogg` | Cidade do Deserto |
| | `region_swamp.ogg` | Pântano |
| | `region_forest.ogg` | Bosque de Cinza, Coração das Raízes, Ninho |
| | `region_desert.ogg` | Areais, Oásis, Acampamento |
| Respiros | `breath_1.ogg` … `breath_4.ogg` | one-shots espaciais esparsos (qualquer subconjunto) |

MMO-first: o áudio pertence ao mundo, não ao jogador. Leitos = textura longa/sem ritmo (pra o loop não aparecer).
Respiros = sons curtos, distantes, ambíguos (vento, estalo, ave) — esparsos por design.
